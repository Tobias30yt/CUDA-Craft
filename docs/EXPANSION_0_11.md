# CUDA Craft 0.11 implementation boundary

The requested target is more than 90% of blocks with complete vanilla behavior,
all game mechanics, both additional dimensions and all mobs. **This target is
not achieved by 0.11.** The 1.21.11 registry contains 1,166 block types; exceeding
90% would require at least 1,050 types with defined and passing behavior checks.
Registering/rendering/placing their states is not that acceptance test.

`block-coverage.csv`, generated by `tools/block-coverage.py`, inventories every
block, groups the currently implemented areas and marks full behavior parity as
unverified. Unclassified blocks are not silently counted as finished.

## Dimensions

Overworld, Nether and End have separate block edits, entities, container states
and chunk streams. Nether/End use the actual dimension types and 256-block-high
chunk layout. Player inventory and health survive travel; the current dimension
is recorded in the root player save. Dimension files live in `DIM-1/blocks.json`
and `DIM1/blocks.json`. Existing Overworld saves remain readable.

Operators can use `/dimension overworld`, `/dimension nether`, `/dimension end`
or append a player name from the console. `/tp` to another player follows their
dimension. Summoning and template placement use the command sender's dimension.
Death outside the Overworld returns the player to the Overworld spawn.

Obsidian frames with an interior 2..21 blocks wide and 3..21 blocks high can be
lit with flint and steel. Standing in a Nether portal triggers travel immediately
in creative or after 80 ticks in survival. End frames accept Eyes of Ender; a
complete inward-facing ring opens the portal. There is a 100-tick arrival
cooldown. Water buckets evaporate in the Nether.

Terrain is an **independent prototype**, not vanilla seed parity: Nether caves,
lava, bedrock ceiling and a safe arrival area; End central island, obsidian
arrival platform and a return portal. Travel currently uses dimension spawn
points, without vanilla 8:1 coordinate linking or nearest-portal search. There
are no generated fortresses, bastions, End cities, outer islands or dragon fight
progression. Breaking a portal frame does not yet invalidate its portal blocks.

## Shared block behavior

- Sand, red sand, gravel, concrete powder and anvils fall in bounded block steps.
  This does not implement vanilla falling-block entities, damage or archaeology.
- Concrete powder hardens next to water.
- Hoes create farmland; water within four blocks hydrates it. Dry unplanted
  farmland reverts to dirt. Seeds, carrots, potatoes and Nether wart can be planted.
- Crops have bounded approximate growth ticks; bone meal advances supported crops.
  Exact random-tick rates, lighting, support checks, mature double-height plant
  conversion, harvest loot and trampling remain incomplete.
- Buttons activate, then release after 20 stone/30 wood ticks. Pressure plates
  react to nearby players and entities. They emit into the existing basic circuit
  model; exact collision shapes, strong-power behavior and all redstone devices
  remain incomplete.

## Validation scope

The simulation suite tests all mob profile save/load paths, isolated dimension
edits, player inventory on round trips, dimension reloads, entity-ID reservation,
portal frame completion, falling sand, concrete hardening, hydration, growth and
button timing. Encrypted independent clients decode both dimensions' chunk layout.

`tools/launch-fabric-client.py --smoke --smoke-dimensions` enters Nether and End
with a real Fabric 1.21.11 client, summons every registered mob type, checks the
received type set, returns to the Overworld and verifies clean shutdown and saves.
Receiving a mob is not proof of correct AI. See `MOBS.md` and `VALIDATION.md`.
